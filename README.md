# Gestão de Frotas

Sistema para gerenciamento e controle de manutenções da frota.

## Sobre

Sistema desenvolvido para auxiliar no controle das manutenções dos veículos da frota, permitindo organizar serviços, acompanhar histórico e centralizar informações.

## Funcionalidades

* Cadastro de veículos
* Registro de manutenções
* Controle de manutenções preventivas e corretivas
* Histórico de manutenção dos veículos
* Consulta de manutenções por veículo

## Objetivo

Facilitar acompanhamento das manutenções da frota, melhorar organização dos serviços e manter histórico dos veículos para auxiliar na gestão.
